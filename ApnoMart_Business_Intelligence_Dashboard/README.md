# ApnoMart Executive Business Intelligence Dashboard

## Project Overview
This project was developed for the ApnoAI Data Analytics Internship, Task 3: The Insight Board — Business Intelligence Dashboard.

The dashboard analyzes sales, profit, product categories, regional performance, and customer segments using Power BI.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Visualization

## Dataset Summary
- Total Sales: ₹1,62,61,998.30
- Total Profit: ₹44,19,736.17
- Total Orders: 1,200
- Overall Profit Margin: 27.18%
- Units Sold: 6,736

Dataset period: May 1 to October 28, 2026.

## Dashboard Features
- Sales, profit, order, and profit margin KPIs
- Sales by category
- Sales trends over time
- Profit by region
- Interactive region filter
- Profitability analysis
- Discount versus profit analysis

## Key Insights
1. Furniture generated ₹35,18,270 in sales.
2. Office Supplies generated the highest category profit at ₹11,76,657.32.
3. The Corporate customer segment generated ₹43,11,027.50 in sales across 307 orders.
